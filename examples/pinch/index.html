Pinch-zoom test

Six hand-rolled masks (no library code) probing WebKit bug 282530 on iOS. Expected there: luminance 200px never renders and 96px vanishes under pinch zoom (verified); alpha (internal <mask>) always renders; composite (two plain alpha layers, canvas-subtract-shape) is the candidate that should both render crisp and survive any pinch — that's what this page is testing.
