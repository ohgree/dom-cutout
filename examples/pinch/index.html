Pinch-zoom test

Six hand-rolled masks (no library code) probing WebKit bug 282530 on iOS. Expected there: luminance 200px never renders and 96px vanishes under pinch zoom (verified); alpha (internal <mask>) always renders; composite (gradient canvas minus a small alpha shape layer, via mask-composite: subtract) is the candidate that should render crisp, survive any pinch, and show no tile seams — that's what this page is testing.
